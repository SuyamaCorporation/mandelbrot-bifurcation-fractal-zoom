# マンデルブロ分岐図フラクタルズームエクスプローラー

マンデルブロ集合をCanvas描画し、マウスクリックでズームイン/アウトできるインタラクティブフラクタルビューア。

## 機能

- Canvas 600×400 でマンデルブロ集合を描画
- 左クリックでズームイン（2倍）、右クリックでズームアウト
- クリック位置を中心に複素平面の表示範囲を更新
- 現在の中心座標・ズーム倍率・表示範囲をリアルタイム表示
- 最大イテレーション数のスライダー調整（50〜500）
- 計算中のプログレスバー表示
- リセットボタン（初期ビューに戻す）

## 技術仕様

- チャンク分割レンダリング（20行ずつ）でUIをブロックしない
- HSV系カラーマッピング（イテレーション数に基づく色付け）
- 複素平面初期範囲: Re(-2.5〜1.0), Im(-1.0〜1.0)
- バニラJS / Tailwind CDN のみ
